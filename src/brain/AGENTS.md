# 开放蝇群内核的维护原则

本文件适用于 `src/brain/` 下今后的修改。目标架构见 `../../docs/PRODUCT-LATEST.md`，首个产品是交易小世界。现有文件仍含待迁移耦合，不得宣称已经全部符合目标架构。

- Life、Social、Identity、History 保持与具体金融产品无关；不要向图、神经动力学或原生 ethology schema 加入 IFS、BUY/SELL、收益、仓位或钱包语义。
- 外部环境通过有来源、版本和顺序的输入进入内核；结果反馈是新的事件，不可覆写旧历史。
- 金融动作在 World/Port 层解释，经过独立风险策略与执行授权才可结算。插件注册本身不授予签名、升级、转账或新资产权限。
- 每项能力使用明确版本。破坏性语义变化生成新版本，保留旧版解析与重放；不要原地改写旧 schema 的含义。
- 完整恢复覆盖全部随机状态、输入、成员变化、学习参数、社会队列及相关世界状态；哈希不能替代实际可获取的数据。
- 原型账本不直接升级成真实资金账本。真实金额使用有精度的整数，明确所有权、负债和不可重复占用规则。
- IFS 质押、客户资产、协议自有资产、服务商保证金及借贷抵押分账；入金不算收益，借款不算净资产增加，浮盈不直接形成回购预算。
- 不因 UI 操作直接修改余额，不因重复提交或重复回执重复结算，不把交易提交等同于成交确认。
- 变更相关边界时验证有意义的不变量：新世界接入不改内核、独立重放、所有者权限、资金守恒、失败恢复。单纯改文档无需运行全量交易或合约测试。
- 涉及真实资金的代码变更不视为已获部署、签名、发送交易或扩大账户授权的许可。
