## 问题

接续 [RELAY-DIRECTION-V1.md](RELAY-DIRECTION-V1.md)：方向信息能进入神经活动但不产生有效运动。本轮回答：在**不改内核（runtime.mjs）、不改连接边与权重、不改运动读出规则**的前提下，感觉输入能否被映射成有效运动。

## 不可能性结果（原标量管线）

反向两条消息经原 `receiveRelayInbox()` 都变成强度 346；从同一初态执行原 `step()`，实际 voltage/refractory/spikes 数组逐位相同。方向在输入转换处丢失，任何策略都无法从该路径恢复方位。该路径确实改变运动（不通信对照第 4 拍起出现身体差异）但不朝目标：0/16 采集、净距离 −128.3。

## 输入源标定（真实历史图，静息，强度 1000）

80 个 food 输入节点全部单点探测（seed 301，32 拍）：48 个无位移、26 个正转、6 个负转。固定选三个（预注册于计划文本）：

| 节点 | 静息转向 | 校准含义 |
| --- | --- | --- |
| 904 | +9°/拍 | 正转源 |
| 941 | −9°/拍 | 负转源 |
| 994 | 0（直行） | 死区/前进源 |

三者均不与运动读出组重叠。`validateMotorSources()` 把索引绑定到连接组哈希 `0x4278c3ca…e843`。

### v1 运行器缺陷（已更正的误判）

v1 冻结运行器从未把选中源路由进刺激（始终刺激整个 80 节点 food 组），因此 v1 motor 臂测的是**饱和全组输入**而非转向；由此得出的「941 在运动态极性反转」是伪影，**静息极性在闭环中成立**（left 方位由 941 完成采集）。v1 报告已删除；v2 运行器逐拍路由单源，缺陷写入计划 limits。教训：刺激路由必须显式断言。

## v2 冻结实验（iff.motor-input-plan/2）

五臂：原神经不通信/标量中继（历史基线原样重放）、motor-off（传输对照，逐拍验证零位移）、motor-single（只正转+死区）、motor-dual（双向+死区）。映射只看：本地观察、一拍延迟消息、本体感受（heading）。控制器 3 节点 + 死区 22.5°，规则冻结后运行 80 配置，每配置双跑全量比对。

| 臂 | 采集 | 平均净推进 |
| --- | ---: | ---: |
| neural-off | 0/16 | 0 |
| neural-relay | 0/16 | −128.3 |
| motor-off | 0/16 | 0 |
| motor-single | 0/16 | +388.6 |
| **motor-dual** | **8/16** | **+754.1** |

motor-dual：ahead 第 135 拍、left 第 151 拍采集（四种种子一致）；right/behind 逼近（+559/+742）但 160 拍未达。**同样的消息、同样的内核，只换输入接线，净推进从 −128.3 反转为 +754.1**。

## 机制核对（来自报告轨迹）

- 误差收缩实测：ahead 9→0、left 70→1、behind 154→89；**right 75→147 不收缩**——9° 步进 + 35/拍位移 + 一拍延迟方位造成 ±180° 附近的过冲极限环，不是极性错误。
- right/behind 的持续推进由**一拍延迟的消息**维持（1200 距离超出本地感觉 1000，无消息时最小模拟完全停摆）——消息价值的直接证据。
- round-2 四方位源 {994, 904, 904, 941}：behind(+180) 与 right(+90) 同用 904，同初态下只有 3 种神经状态。反向坐标在**新映射下输入不同**（v1 诊断中旧标量路径相同）。
