# FlySwarm 首轮升级与 SWARM 调研

日期：2026-09-18。来源：本仓库再评估建议及 https://www.swarm.family/ 本次页面抓取。范围是本地工程原型；未部署、未签名、未审计竞品合约。

## 1. 采纳方向与本轮交付

采纳“以果蝇连接组为起点的开放群体智慧基础设施”作为升级方向，不以生命数、神经元数或链上事件数代替能力证据。北极星仍是：发现者离开后，新成员能否经验证的经验降低学习成本，并保持任务成绩与失败率。

本轮先落实再评估中的个体学习缺口，不声称七个缺口均已解决：

- 新增 `src/brain/association-learn.mjs`，版本 `context-association/1`，独立状态 `iff.association-state/1`。
- 按 context + cue 保存有符号关联值；摄取与损伤反馈可分别增强或反转关联。
- 单条资格迹显式绑定观察序号，延迟降低更新幅度，过期拒绝；新观察替换旧迹；一个结果消费一次资格迹。
- 单调序号、显式时钟、范围校验；不读取墙钟，不使用隐含随机数，不原地修改调用者状态。
- 遗忘向中性衰减；冻结同时禁止更新和遗忘，切换冻结状态清空资格迹。
- 完整 JSON 状态包含参数、关联、资格迹、时间与序号，可校验恢复。容量上限 256，满时拒绝新关联而不是暗中删除历史。
- `associationInput` 将关联投影到现有三通道感觉输入，仍属于工程适配器，不是神经突触学习或动作规划。
- 旧 `learn.mjs`、runtime、schema、quorum、Soul、图数据和创世包均不修改。

### 使用边界

这是 opt-in 模块，**尚未接入生产 colony/kernel、网页或神经觅食评测**。调用端必须保留独立学习状态并显式采用 `associationInput`；不能将新状态冒充旧 overlay，不能自动继承或全网同步。

`outcome` 只接受 ingestion/damage 类型，但类型校验不能证明事件真实。可信任务结算器必须检查实际摄取/损伤，再绑定先前观察序号调用它。远程消息不得直接作为结算结果。该模块不改变身体能量，也不修复旧 runtime 的 food 信号增能语义；要改该语义必须另立 runtime 版本并保留历史重放。

同一 cue 的含义仍由任务定义；这里没有实现跨物种语义协商。单资格迹是有意收窄的参考实现，不处理多线索长期信用分配。updates 只是记账，不是智力或科学证据分数。学习器恢复不等于完整世界恢复；世界、通信队列、神经状态仍需各自保存。

### 已执行验证

`node --test tests/association-learn.test.mjs tests/kernel.test.mjs`：12 项通过，0 项失败。

完整 `npm test` 后台运行约 47.2 秒：384 项，381 通过、2 失败、1 跳过。失败位于本轮未修改的 `tests/life-colony.test.mjs`：`sampleDescent is deterministic per rng and reports the child generation`（断言 false !== true）和 `expected crossover mix`（读取 undefined.pct）。候选研磨测试本身通过但耗时约 41.5 秒，因此首次工具的 30 秒超时不代表挂起。独立 5 秒超时诊断也不能当成业务失败结论。未修改并行表型代码来掩盖失败。

`npm run build` 通过（约 6 秒），存在 >500 kB 分包警告；新增代码与测试的 `node --check` 通过。仓库整体 `git diff --check` 指出产品文档末尾已有空行问题；没有对并行改动做全局格式化。

覆盖情境与线索隔离、正负关联、反转、延迟/过期/重复反馈拒绝、遗忘、冻结、JSON 恢复、非法输入，以及旧 overlay 与 kernel 兼容。它们证明工程规则可执行，不证明真实 MaleCNS 学习、T4 胜出、泛化或独立复现。

以下仅为页面自述，不是源码或链上核验结论。

| 页面披露 | 可借鉴 | 必须保留的区别 |

## 3. 后续升级门槛（未实现）

1. **版本与复算包**：绑定源码、图、适配器、学习参数、训练/评测输入及依赖指纹，保存可用数据而不只有哈希。
2. **受控关联任务**：可信世界摄取/损伤结算；训练后冻结，比较无学习、清空状态、打乱反馈、反转与旧任务回归。先测行为而非更新计数。
3. **神经贡献归因**：同一感觉适配器接简单控制器与神经模型，冻结开发选择，在独立环境上比较并记算力成本。
4. **可撤销经验库**：经历/情境知识/技能分开，训练域索引与留出隔离，来源去重、适用期、反例与依赖撤销，不全网广播冠军权重。
5. **局部多生命传承实验**：独立状态、合法局部观察；通信关闭、空库、打乱库、发现者退出、全员换新对照。报告全部失败和负迁移。
6. **异构开放接口**：Drosophila profile、新版本能力协商、任务单位与时间语义，再接第二真实生物物种。旧 MaleCNS schema/quorum 不静默放宽。
7. **产品透明度**：借鉴 SWARM 的实际事件因果链与权限表；展示模型/任务/学习器版本和证据等级，不先做伪集体动画来代替实验。

近期不要重部署 Soul，不扩大真钱权限，不上线多脑云集群；先让一条可证伪的学习闭环成立。
