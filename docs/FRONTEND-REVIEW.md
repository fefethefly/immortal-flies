# 前端验收清单（交易世界六视图）

验收地址：http://127.0.0.1:4173/swarm.html（`npm run dev -- --port 4173`；可选后端 `npm run server`，8787）。

按顺序过一遍即可；每项都对应一条已验证的行为。全部是纸面数据（SIM），不涉及真实资金。

## 1. 交易场（默认视图）

- [ ] 左坑右案：画布 5 只蝇绕行，点蝇选中，底部显示编号/方向/纸面价格
- [ ] 四只风琴键（花蜜/威胁/光/暗）注入刺激，有冷却与通知；价格与账本标注 SIM
- [ ] 「Settle now」立即结算：血统新增一条（退役+繁衍），不报错
- [ ] 暂停按钮冻结 tick，再按恢复；每秒一个 tick（页面可见时）
- [ ] 「改变一次经历」创建个人分支（通知带分支 id）；「重放因果链」跳到 Colony

## 2. Colony（现场）

- [ ] 社会状态：CONSENSUS / SPLIT / NO_QUORUM / STALE 之一 + 买压/卖压/弃权权重
- [ ] 蜂巢压力计：指针随聚合压力摆动（0=卖压，100=买压）
- [ ] 现场：最近 16 个 tick 六类事件（感觉/行为/记忆/成交/社会/风控）逐列落地
- [ ] 因果条：起因 → 箭头 → 结果；点击一条出现「因果重放」面板（节点按 tick 排序）
- [ ] 影响列表：谁动了谁（世界/蜂巢/蝇编号）
- [ ] ask 通道：七个固定问题即时得到本地回答（带事件引用）；后端可用时可自由提问

## 3. Intent

- [ ] 端口管线七步（行为分布 → TradePort → RiskPolicy → CreditPolicy → 授权 → Executor → 回执）
- [ ] 每只蝇双栏卡片：原生行为学（动作、左右运动、感觉计数）与端口读取（方向/置信）分栏；转向标「转向」

## 4. Risk

- [ ] 五个 KPI：蜂巢权益、流动性、集中度（对上限）、回撤（对警戒线）、信用 top
- [ ] 仓位表（份额条对集中度上限）+ 策略拒绝记录 + 版本化策略参数

## 5. Execution

- [ ] 统计行：成交数、买/卖笔数与名义量、已收税、被标记数
- [ ] 回执表：tick/蝇/方向/名义额/滑点/税/裁定（PASS 或 FLAG+原因）

## 6. Vault

- [ ] 用户金库标「未接入」（份额 0、退出队列为空）——按设计不开放
- [ ] 蜂巢金库（纸面）：净值、高水位、已实现盈余、回购预算、费用、准备金 + 净值/高水位逐 tick 柱图
- [ ] 说明文字：浮盈不形成回购预算，入金不算收益

## 7. IFS

- [ ] 官方代币事实：名称/符号/链/税/合约地址（链接 BscScan）
- [ ] 六个纸面面板：买入未开放（P3）、锁仓门槛、抵押只可支撑一次额度、费用、价值预算、回购（仅已实现盈余触发，路由未接通）
- [ ] 说明文字：未经核验不把锁仓称为销毁；税进钱包不是回购；金库地址未公布
- [ ] 不出现「打给 CZ」或把转入地址写成销毁
- [ ] 纸面「回购 / 销毁」读作预算，不读作已执行 burn

## 8. 解释抽屉（LLM 边界）

- [ ] 五个标签：解释（步骤带证据引用）、检索（按类别过滤）、候选计划（PASS/REJECT+原因）、工具白名单（全部只读、不可签名）、策略验证（版本化参数）
- [ ] 无 LLM 密钥时标「本地确定性 · 模型缺席仍可运行」；ESC 关闭
- [ ] （后端+密钥时）解释/ask 出现远端叙述层，证据步骤不变

## 9. 持久化与兼容

- [ ] 刷新页面：tick 与现场/回执/因果条不归零（localStorage 快照恢复）
- [ ] 移动宽度（≤390px）七视图无横向溢出；减少动态效果开启后无异常

## 已知边界（不是 bug）

- 所有数字 SIM；IFS 是真实主网代币但本页只有纸面面板；用户金库按 PRODUCT-LATEST §11 未开放
- 后端未接 LLM 密钥时解释层为本地确定性实现（P1 退出条件：模型缺席仍可运行）
- 事件窗口有界（最近 120 事件 / 96 压力 / 96 金库历史），旧事件被裁剪，因果条同步修剪
