# V6：生物学脊梁

日期：2026-09-15。前端可以后做。这一版先定活的是哪一只动物、数据怎么流、哪一层不许冒充科学。

## 1. 用哪一个脑

**Canon 是成年雄蝇 MaleCNS v1.0，不是幼脑。**

| 数据集                   | 规模                                                | 和本产品的关系                                                                                                                                                                    |
| ------------------------ | --------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **MaleCNS v1.0**         | 官方约 166,700 个神经元；本仓库全量注释图约 161,839 | **唯一官方身份。** 成体趋光、嗅觉觅食、机械感觉逃逸、左右下行/运动，都能在同一套 body ID 上读出来。CZ / YZi 说的永存对象也是这只成体 CNS。                                        |
| 幼虫全脑（Winding 2023） | 约 3,016 个神经元                                   | 科学上更完整、更好实时跑。但是另一发育阶段：蠕动、翻滚、化学趋向，没有翅膀，没有成体下行飞行回路。编号与 MaleCNS 不能混用。以后可以单独开 `larva-cns:2023` 身份，不能替换 canon。 |
| FlyWire                  | 成体雌蝇脑，约 13.9 万，不含腹神经索                | 缺 VNC，运动读不全。                                                                                                                                                              |
| `iff-neural-16-v1`       | 16 节点                                             | 祭坛身份原型，行为启发。                                                                                                                                                          |
| `iff-swarm-lif-v1`       | 24 节点                                             | 交易场占位反射。**不是脑。**                                                                                                                                                      |

幼脑如果当主脑，叙事和科学会对不上：永存的是成体连接组，交易映射的是成体趋避。计算便宜不能成为换动物的理由。

## 2. 16.7 万是身份，不是每一跳都在浏览器里算完

不能宣传「完整大脑在网页或 BSC 合约里实时跑」。

| 层          | 跑什么                                                             | 神经元从哪来                |
| ----------- | ------------------------------------------------------------------ | --------------------------- |
| 身份 / 永存 | `male-cns:v1.0` 清单、body ID、检查点哈希                          | 官方连接组                  |
| 现场蜂群    | 同一数据集抽出的感官–运动子图（当前 1,400 个节点、同一套 body ID） | 官方注释种子 + 一跳显著连接 |
| 全量重放    | 本地生成的注释全图（约 16.2 万）                                   | 权重阈值后的显著连接        |
| 链上        | 身份、状态承诺、成交，不跑 LIF                                     | 无                          |

子图不是另一种果蝇。它是同一只 MaleCNS 上、被点名的嗅觉/味觉、逃逸、光感受器、左右下行与运动神经元。全量图换上时，映射规则和 body ID 保持不变。

## 3. 数据只准这样流

```
世界事件
  → 适配器（环境 / 行情 / 以后的仓位内感受）
  → 编码器 sensory-groups/1
      把强度打到官方分组：food / threat / light
  → MaleCNS 图 + iff-runtime/1 整数 LIF
      边权是官方连接强度；递质符号是项目规则
  → 解码器 motor-balance/1
      数的是 left / right 等官方分组的发放
  → 行为 iff.ethology/1
      REST / FORAGE / AVOID / EXPLORE
  → 金融 iff.finance/1
      BUY / SELL / HOLD
  → 纸面账本或 Vault
      看不见神经元，也不能把交易字段写回脑状态
```

硬边界：

1. **适配器**只许输出有界感觉量。行情变食物/威胁是产品编码，不是果蝇懂 K 线。
2. **编码器**只许打到已登记的官方神经元分组。不许为「暗场」「盈亏」临时造一组假细胞，除非先在 MaleCNS 注释里找到对应类型并写进 provenance。
3. **动力学**是整数 LIF，不是离子通道，不是生物时间常数。
4. **行为解码只看发放，不看行情数字。** 上一版用 `threat > food` 的输入强度当行为，已经断开生物学。
5. **金融层在连接组之外。** 趋近→买、退避→卖、仓位过重加卖压，全部写在 `finance.mjs`，并标明产品层。
6. **账本结果可以再进适配器**，必须当成新的输入批次，带来源和过期；不能改边权，不能改 body ID。
7. **幼脑、FlyWire、16 节点、24 节点**若要跑，必须换 `dataset` / `model`，走迁移事件。不许静默替换。

## 4. 一只交易果蝇是什么

一只活体 = **一份 MaleCNS 会话 + 一本账**。

- 图是共享的（`male-cns:v1.0`）。
- 状态是私有的（电位、不应期、随机种子、暴露量、历史根）。
- 性格来自种子，不来自另一张假连接组。
- 淘汰与繁衍换的是会话种子和账本，不换物种。

`src/brain/colony.mjs` 按这个定义跑，交易场已改读 colony（`src/brain/flyswarm/pit.mjs`，真实 MaleCNS 1,400 节点子图）。`src/swarm.mjs` 的 24 节点占位仅剩首页纸面场，继续标明占位。

## 5. 暗场、多巴胺、盈亏

这些可以做，但要先有细胞，再有故事。

| 想要的效果   | 正确做法                                                                 | 错误做法                         |
| ------------ | ------------------------------------------------------------------------ | -------------------------------- |
| 暗场         | 把 `light` 降下去，或在注释里选出 R1–R6 / 钟神经元后再加分组             | 在 24 节点里加一个叫 dark 的电流 |
| 仓位内感受   | `finance.mjs` 的产品修正，或映射到已鉴定的 PAM / PPL 等，并写 provenance | 声称果蝇有「钱包感受器」         |
| 盈亏强化学习 | 新模型版本 + 可塑性参数进检查点                                          | 改边权却说还是 MaleCNS v1.0      |

Stonkfly 用 PAM11 / PPL101 做盈亏，是另一种产品编码。要做就引用官方类型名和 body ID，另开编码器版本。
